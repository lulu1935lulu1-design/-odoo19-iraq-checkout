## English

This is the first public open-source release of **Iraq Checkout for Odoo 19**.

The project provides a focused Odoo 19 checkout extension for Iraqi e-commerce workflows, especially stores that rely on phone-first communication and Cash on Delivery.

### Highlights

- Compatible with **Odoo 19.0** Website/eCommerce.
- Configurable required/optional email at checkout.
- Configurable required/optional phone at checkout.
- Iraqi phone normalization to international `+964` format.
- Supports common Iraqi local formats such as `07XX XXX XXXX`.
- Preserves valid non-Iraqi international phone numbers.
- Checkout labels reflect required/optional state.
- Multi-website friendly configuration.
- Arabic translation included.
- Public contribution, security, architecture, roadmap, and testing documentation.
- GitHub Actions checks and an automated obvious-secret guardrail.

### Security and repository boundary

This public release contains only custom add-on code and public documentation. It does not include Odoo Enterprise source code, merchant/payment credentials, API keys, customer data, production database dumps, production logs, or private infrastructure configuration.

### Installation

1. Copy the `lunara_checkout_iq` directory into an Odoo custom add-ons path.
2. Reload/restart Odoo according to your deployment process.
3. Update the Apps list.
4. Install **Iraq Checkout for Odoo 19**.
5. Configure email and phone requirements from Website settings.

### Verification status

The public repository includes automated syntax/structure/security checks and unit-level phone-normalization coverage. Full reproducible Odoo 19 runtime install/upgrade evidence is tracked separately in the repository and should not be assumed beyond evidence actually published.

## العربية

هذا هو **أول إصدار عام مفتوح المصدر** من مشروع **Iraq Checkout for Odoo 19**.

المشروع يضيف تحسينات عملية لمرحلة إتمام الطلب في Odoo 19 للمتاجر الإلكترونية في العراق، وخصوصًا المتاجر التي تعتمد على رقم الهاتف والدفع عند الاستلام.

### أهم المزايا

- متوافق مع **Odoo 19.0** وWebsite/eCommerce.
- جعل البريد الإلكتروني مطلوبًا أو اختياريًا أثناء Checkout.
- جعل رقم الهاتف مطلوبًا أو اختياريًا أثناء Checkout.
- توحيد أرقام الهاتف العراقية إلى الصيغة الدولية `+964`.
- دعم الصيغ المحلية الشائعة مثل `07XX XXX XXXX`.
- الحفاظ على أرقام الدول الأخرى وعدم تحويلها إلى أرقام عراقية.
- إظهار حالة الحقول المطلوبة/الاختيارية في واجهة Checkout.
- مناسب للـMulti-Website.
- يتضمن ترجمة عربية.
- يتضمن وثائق عامة للمساهمة والأمان والهيكلية وخطة التطوير والاختبارات.
- يتضمن GitHub Actions وفحصًا آليًا للأنماط الواضحة للأسرار.

### الأمان وحدود المستودع

هذا الإصدار العام يحتوي فقط على كود الـCustom Add-on والوثائق العامة. لا يحتوي على كود Odoo Enterprise أو مفاتيح API أو بيانات دفع أو Tokens أو بيانات زبائن أو نسخ قواعد بيانات الإنتاج أو Logs الإنتاج أو إعدادات البنية التحتية الخاصة.

### التثبيت

1. ضع مجلد `lunara_checkout_iq` داخل مسار Custom Addons في Odoo.
2. أعد تحميل/تشغيل Odoo حسب بيئة النشر.
3. حدّث قائمة Apps.
4. ثبّت **Iraq Checkout for Odoo 19**.
5. اضبط متطلبات البريد والهاتف من إعدادات Website.

### حالة التحقق

المستودع العام يتضمن فحوصات آلية للبنية والصياغة والأمان واختبارات على منطق توحيد أرقام الهاتف. أما دليل التثبيت/الترقية الكامل القابل لإعادة التشغيل على Odoo 19 فيتم توثيقه بشكل منفصل، ولا يجب اعتبار أي سيناريو ناجحًا إلا إذا نُشرت له أدلة فعلية.
