# Changelog

All notable public changes to this project will be documented here.

The format is inspired by Keep a Changelog and the project follows Odoo-style module versioning.

## [19.0.2.1.0] - 2026-08-08

### Added

- Initial public open-source release for Odoo 19.
- Configurable email requirement at website checkout.
- Configurable phone requirement at website checkout.
- Iraqi phone normalization to `+964`.
- Validation for Iraqi-formatted numbers while preserving non-Iraqi international numbers.
- Checkout label/required-field integration.
- English and Arabic project documentation.
- Security and contribution policies.

### Notes

- This public repository contains custom add-on code only.
- Odoo Enterprise source code, production credentials, databases, and customer data are not included.
