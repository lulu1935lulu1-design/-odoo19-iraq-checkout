# Roadmap / خارطة الطريق

This roadmap describes community-oriented goals. It is not a promise of release dates.

## Near term

- Add repeatable Odoo 19 installation tests.
- Expand phone-normalization test coverage.
- Add Arabic translations for administrator-facing labels/help.
- Add checkout accessibility checks.
- Add screenshots and a short demo using sanitized data.
- Document tested Odoo 19 deployment patterns.

## Medium term

- Improve Iraqi phone validation using clear, documented rules without breaking international numbers.
- Add optional Iraq-focused address helpers through separate, reviewable components.
- Improve multi-website test coverage.
- Publish upgrade notes for future Odoo 19 point changes.
- Add contributor-friendly development tooling that does not require proprietary source code.

## Non-goals

The core project will not:

- include Odoo Enterprise source code;
- embed merchant credentials or production secrets;
- become a payment gateway implementation;
- hardcode one company's private workflow;
- silently send customer information to third-party services.

---

## العربية

### قريبًا

- اختبارات تثبيت قابلة لإعادة التشغيل على Odoo 19.
- توسيع اختبارات تحويل الأرقام العراقية.
- ترجمة عربية أفضل لواجهة الإعدادات.
- فحوص Accessibility لصفحة Checkout.
- صور توضيحية وتجربة ببيانات غير حساسة.

### لاحقًا

- تحسين قواعد التحقق من الأرقام العراقية مع الحفاظ على الأرقام الدولية.
- إضافات مستقلة لمساعدة العناوين العراقية إذا كانت مفيدة للمجتمع.
- توسيع اختبارات Multi-Website.
- توثيق الترقية والتوافق مع تحديثات Odoo 19.

### خارج نطاق المشروع الأساسي

لن يحتوي المشروع على كود Odoo Enterprise أو أسرار المتاجر أو بيانات بوابات الدفع، ولن يرسل بيانات العملاء إلى خدمات خارجية بصمت.
